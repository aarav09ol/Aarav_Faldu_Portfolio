# Aarav Faldu Portfolio

Responsive portfolio website built with HTML, CSS and JavaScript.

## Before publishing
- Replace `assets/profile-placeholder.svg` with your profile photo and update the image path in `index.html`.
- Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
- Review project and education descriptions.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → main → /(root) → Save.
